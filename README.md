# 🐾 dither_animals Showcase Website

An interactive retro-aesthetic showcase website for the [`dither_animals`](https://pub.dev/packages/dither_animals) Flutter package.

Live interactive Bayer matrix dot-dither playground, animated chibi mascots, interactive poke ripple physics, dot-matrix customization studio, and live Flutter code generator.

---

## ✨ Features

- 🐾 **50 Animated Bayer Dither Animals:** Live interactive canvas rendered with customizable Bayer dot-matrix dithering (Square, Round, Diamond, Cross).
- 🎬 **Grand Mascot Parade Loading Screen:** All 50 mascots march one-by-one along a smooth parabolic arc (lower-right → summit center → lower-left) with procedural 8-bit footstep audio.
- 🎨 **Dot Matrix Visualizer:** Interactive threshold and dot-size controls to inspect how Bayer 8×8 matrix ordered dithering transforms grayscale gradients into retro pixel art.
- 💻 **Live Flutter Code Generator:** Copy-paste ready code snippets for `DitherAnimal`, custom Bayer dithers, and poke interaction handlers.
- 🔊 **Web Audio Synthesizer:** Pure procedural 8-bit Web Audio API sound effects (boing, steps, sparkles, fanfare) with 0 external sound asset dependencies.
- 🎨 **Warm Sunset Aesthetic:** Soft gradient clouds, subtle hand-drawn accents, and nostalgic 90s handheld retro aesthetic.

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ or Bun

### Installation

```bash
# Clone the repository
git clone https://github.com/ayan15888/ditherWebsite.git
cd ditherWebsite

# Install dependencies
npm install
# or
bun install

# Start local development server
npm run dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
